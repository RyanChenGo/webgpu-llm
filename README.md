# WebGPU LLM

How to use?

Open ryanchengo.github.io/webgpu-llm and download an HTML.

We suggest you to download the webpage directly in your computer.
It will be saved as an HTML file.

But, please pull the model first(need WiFi) and turn off WiFi to load it completly offline.

Next time, when you visit again the HTML, you don't have to pull it again since the model is saved in the Browser Cache.
